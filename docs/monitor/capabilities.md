# 招聘 Monitor 能力矩阵

对象：BOSS直聘 macOS 客户端 1.7.4，已登录招聘账户，2ndscreen 测试屏幕 `monitor-b`。验证时间：2026-10-04 19:10–19:20（+08:00）。

结论有三种：

- **观察到**：在真实客户端上看到了，有夹具为证。
- **未观察到**：这次没看到。可能是条件不具备，也可能是只读约束不允许操作。不代表客户端不支持。
- **不支持**：观察到客户端确实没有这个能力。

夹具路径都相对 `monitor/fixtures/ax/`，写法是 `场景#步骤序号`，步骤序号从 0 开始。

### 1.9 驱动层发现（给 C）

- 读取时始终带 `--window-id`：附件预览打开期间，不带它会报 `no window on screen`。
- CLI 的 `elements` 只有 role、label、value、frame、actions，**没有 enabled 和 selected**。
- 在线简历加载等异步状态，要等 AXImage 尺寸变化，不能固定等待一段时间。
- 本次所有点击都是 `--index` 加 `event.click`，全部生效。
