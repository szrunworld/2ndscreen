## 协调闭环

每次交付均检查文件归属、差异、失败路径和测试结果，再接受或派回。消息检查使用 FIFO Delivery，必须处理并 ack 当前批次后继续读取；已纠正重复读取旧批次导致后续要求未及时到达的问题。依赖满足后自动派发下一任务，不以状态汇报作为批次结束。已接受的 worker 均明确释放或按 Orca 的 external_terminal / user_takeover 收据保留，不终止用户拥有的终端。

Orca 最终清理检查：没有尚欠处理的 reclaimable worker；实现任务均已交付，保留的终端遵从 external_terminal / user_takeover 所有权收据。P0 的环境阻断没有被标为真实采集成功。
