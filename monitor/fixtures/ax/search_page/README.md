# search_page：搜索牛人

点左侧导航『搜索』（AXLink）进入；看完后在结果区滚动，再滚回顶部，然后点『消息』返回。**没有在任何输入框中输入。**

## 结构（窗口相对坐标）

- **顶部输入**
  - 『城市』：AXTextField，位于 (344,38)；
  - 岗位下拉：当前值『Vue 前端 研发工程师』；
  - 关键词：AXTextField，位于 (592,32)，值为空。旁边的 StaticText『编程』是灰色占位文字，不是已经输入的内容；
  - 搜索按钮：无标签 AXGroup，位于 (1120,32)。
- **热门词**：一排『ux / 编程 / vue …』，每个是一个可按的 AXGroup，旁边有『换一换』。
- **筛选**：学历要求、院校要求、经验要求、年龄要求，选项都是 AXGroup 加 StaticText；『其他筛选』包括性别、薪资区间、牛人活跃度、跳槽频率、求职状态、牛人职位要求、专业；另有『筛选说明』『清空筛选』。当前选中的项（例如『不限』）只在视觉上高亮。
- **结果头**：『根据热门词为您检索到以下牛人』。排序有『综合排序 / 活跃优先 / 匹配度优先』，复选框有『过滤近14天查看』『近30天未和同事交换简历』。
- **结果卡**：每条结果是一个可按的 AXLink，宽 1003。它的标签串联了整张卡片的文字。子元素包括：头像 AXImage、姓名 StaticText（平台打码为『X**』）、『热搜』、活跃度、年龄、年限、学历、求职状态、薪资、简介、技能标签、『期望城市』、『职位』（后面是公司和岗位）、『院校』（后面是学校和专业）、『近14天你』『首次看到』『该牛人』。
- **右栏**：『搜索畅聊卡』『查看详情』『我的订阅』（本账户订阅的岗位，含『该职位已下线，无法查看订阅牛人』）。

## 观察结论

- **结果可读**：搜索结果是 AX 元素，不是图片。结论：可读。
- **默认结果**：不输入关键词也有结果（按热门词检索）。
- **打码姓名**：结果里的姓名已经被平台打码，`display_name` 只能拿到『X**』，不能作为身份。
- **滚动**：结果区可以后台滚动：滚 10 格后，看到的结果从 3 条增加到 7 条。滚出视口的元素仍留在树里，frame 被裁成高度 1 或贴顶，需要按可见区域过滤。
- **未观察到**：
  - 输入关键词之后的结果；
  - 无结果时的文案（`empty_confirmed` 的界面依据）；
  - 加载中的状态。
  
  这三项都需要输入，只读阶段没有做。
