# resume_overlay：在线简历弹层与转发对话框

在候选人N 的会话里点了『在线简历』。

## 步骤与点击

| # | 操作 | 结果 |
| --- | --- | --- |
| 0 | 点『在线简历』，等约 3.5 秒 | 出现 AXWebArea（734×875），里面的 AXImage 还是 1×1，说明正在加载 |
| 1 | 再等约 3 秒 | AXImage 变为 734×875；右侧侧栏出现『收藏 / 转发 / 举报』（各是一个 AXGroup 加 StaticText）、AXButton『继续沟通』，以及状态行『沟通中』『，14:33』『 向您发起沟通，沟通职位 』『视觉算法工程师』 |
| 2 | 点侧栏『转发』 | 弹出『转发』对话框，左侧有三个页签：**站内同事 / 转发至其他 / 邮件转发**，默认是站内同事。表单包括：AXTextField『姓名、职位、邮箱』、AXTextArea『请输入留言』（0/200）、AXCheckBox『连同聊天记录一并转发』，提交按钮是 AXLink『转发』 |
| 3 | 点左侧『邮件转发』 | 表单变为：AXTextField『请输入收件人邮箱』、『最近联系：』下面的历史收件邮箱芯片（已脱敏）、『请输入留言』，提交按钮是 AXLink『转发』；这一页没有『聊天记录』复选框 |
| 4 | 点左侧『转发至其他』 | 显示一张 456×299 的 AXImage 分享卡片，截图上能看到候选人摘要和二维码，文字不在 AX 里。另有提示『右键复制图片发送至微信好友』 |
| 5 | 点对话框右上的关闭（无标签 AXGroup） | 对话框关闭，回到弹层 |
| 6 | 点弹层右上的关闭（无标签 AXGroup，窗口相对 1274,12） | 回到会话详情，元素序列与打开弹层前相同 |

所有输入框都没有输入，提交按钮『转发』、侧栏的『收藏』『举报』『继续沟通』都没有点。

## 观察结论

- **正文是一张图**：在线简历正文只有一个 AXImage，没有文字树（`x_is_image_body`），与已有能力矩阵一致。
- **加载判断**：AXImage 的尺寸从 1×1 变成实际大小，可以用来判断加载完成。
- **邮件转发**：客户端有『邮件转发』，可以把简历转到任意收件邮箱。表单需要填收件邮箱（还有可选留言），然后点提交『转发』。邮件里具体带什么内容（附件还是链接、有没有候选人标识）没有观察到，需要 N 阶段在用户授权下实际发一次才能确认。
- **侧栏状态文案**『向您发起沟通』可以作为『牛人发起』的证据。
- 转发对话框和弹层的关闭按钮都没有文字标签，只能按几何位置定位：都在各自容器的右上角。
