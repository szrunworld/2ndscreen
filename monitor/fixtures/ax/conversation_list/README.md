# conversation_list：消息页会话列表

**场景**：左侧导航『消息』。顶部页签依次是『全部 / 新招呼(N) / 沟通中 / 已约面 / 更多▾』，下面是子筛选『全部 / 未读』和『批量』。左栏是会话列表，右侧是会话详情；没有选中会话时，右侧显示『未选中联系人』和『列表只展示近30天的联系人』。

## 步骤与点击

| # | 操作 | 结果 |
| --- | --- | --- |
| 0 | 点页签『全部』 | 列表前 10 行都带未读角标 |
| 1 | 点页签『新招呼(504)』 | 详情区清空；可见行与『全部』前几行相同 |
| 2 | 点子筛选『未读』 | 录制期间新到一条招呼，计数变为 505，新行排在第一行 |
| 3 | 先点子筛选『全部』，再点页签『沟通中』 | 共 4 行，末尾显示『没有更多了』 |
| 4 | 点页签『已约面』 | 显示『暂无牛人』 |
| 5 | 点『更多』 | 下拉菜单：已获取简历、已交换电话、已交换微信、收藏、不合适、牛人发起、我发起、道具来源、群聊、管理分组、新建分组 |
| 6–10 | 依次点『更多』→已获取简历 / 牛人发起 / 我发起 / 已交换电话 / 已交换微信 | 依次为 2 行 / 与新招呼相同的行 / 暂无牛人 / 暂无牛人 / 暂无牛人 |
| 11 | 回到『全部』，在列表上后台滚轮滚动 3 次（按坐标、按 index、按页） | 每次都返回 ok，但列表没有变化 |

『已交换电话』『已交换微信』只是列表筛选，不是交换动作，经协调者批准后才点击。『收藏』『不合适』『道具来源』『群聊』『管理分组』『新建分组』没有点。

## 观察结论（给 E / H）

- **行结构**（窗口相对坐标）：每一行是一个可按的 AXGroup，x=120、宽 384、高 76，最后一行被裁成高 28。行内元素：
  - 未读数：StaticText，x≈167，只有未读时才有；
  - 时间：StaticText，x≈464（『19:03』或『昨天』）；
  - 姓名：AXGroup 和它的 StaticText，x=192；
  - 岗位：AXGroup 和它的 StaticText，紧跟在姓名后面；
  - 消息预览：StaticText，y 比姓名大 27 左右。
- 我方最后一条消息的状态前缀是独立的 StaticText：`[已读]` 或 `[送达]`。
- 候选人发来的附件，在预览里显示为 PDF 文件名。
- 页签的选中态、子筛选的选中态、『新招呼』右上角的红点、『更多』变绿，都只在视觉上可见，AX 里没有。要判断当前在哪个页签，只能依靠『最后一次点击了哪个页签 + 列表内容』，或者截图。
- 『新招呼(N)』页签标签里的 N 会实时变化（504→505）。左侧导航『消息N』里的 N 是另一个计数，录制期间从 619 变到 620。
- 列表只暴露可见的大约 10 行。后台滚轮对会话列表无效，只读阶段没有找到看到更多行的方法。
- 空列表显示『暂无牛人』，列表到底显示『没有更多了』。
